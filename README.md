# PyGameboy
A simple gameboy emulator built in Python. Name will be changed once it has any interesting functionality.

## Features
Currently, little to nothing.
- Graphical interface in greyscale
- Able to pass cpu_instrs.gb Test Rom
- Unable to run more complicated Rom's currently

## Requirements
The project is built entirely using Python. NumPy and PyGame are required. All files must remain in the same directory.
